# Análise de Avaliações Negativas com NLP (spaCy)

## Objetivo

Identificar os principais motivos de avaliações negativas dos clientes utilizando técnicas de Processamento de Linguagem Natural (NLP) com spaCy, transformando comentários textuais em insights de negócio.

## Dataset

- Olist Brazilian E-commerce Dataset (Kaggle)

## Tecnologias

- Python
- Pandas
- SpaCy
- Matplotlib
- Seaborn
- Kaggle Notebook

## Principais análises

- Comportamento dos clientes ao expressarem seu feedback.
- Impacto da velocidade de entrega na avaliação final.
- Impacto do SLA de envio do vendedor na satisfação do cliente.
- Comparação entre avaliações com e sem comentários textuais.

## Principais resultados

- O atraso na entrega foi identificado como um dos principais motivos de avaliações negativas.
- Clientes tendem a utilizar comentários textuais principalmente quando enfrentam problemas durante a compra.
- A aplicação de NLP com spaCy permitiu transformar milhares de avaliações em texto em informações estruturadas, suprindo a ausência de indicadores diretos no dataset para esse tipo de análise.
